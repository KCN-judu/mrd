# v1.0.0 - Indexed Boundary-Native Polygon Engine

Local release tag: `v1.0.0-indexed-polygon-engine`

This release preserves the complete v0.9 polygon references and makes the
prepared indexed polygon path the production default. One
`PreparedPolygonContext` owns normalized topology, boundary metadata,
orthogonal edge indexes, reflex groups, and base coordinates. Production uses
the orthogonal sweep validator, indexed aligned-reflex Definition 7 enumerator,
incremental indexed completion, shared arrangement recovery, and difference-
array validation.

Release campaigns compare complete chord families, endpoint and clean
certificates, representation/flow results, selected and added cuts, optimum,
canonical rectangles, and both validators. The committed 3x3, 4x4, extended,
negative, native A-H, and scaling populations report zero disagreements.

This release does not claim the full Soltan--Gorpinevich `O(n log n)` polygon
enumerator, formal degenerate holes, the optimized Theorem 8 implementation,
or an almost-linear exact-flow backend.
