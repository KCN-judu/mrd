# Clean Complete-Bipartite Family

The finite-grid artifact does not yet include a proved integer realization of
the continuous family. `rect-cli generate --family clean-complete-bipartite`
therefore rejects every positive `t` explicitly rather than emitting a shape
whose chord graph would only be dense or would contain unintended chords. A
3x3 plus pentomino is a useful `K_{2,2}` exploratory fixture, but it shares
boundary endpoints and is not a clean certificate under Definition 9.1.

This is a known v0.5 scope gap, not evidence for the full Theorem 9.2 family.
