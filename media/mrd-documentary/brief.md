# Production Brief

## Audience

Mathematically curious viewers, software engineers, computational-geometry
readers, and open-source researchers. They understand graphs and algorithms at
a high level but should not need prior knowledge of rectangular dissection,
dominance embeddings, biclique partitions, or flow reductions.

## Core promise

Show, with source-backed geometry, how a 1993 structural theorem becomes a
current exact and auditable implementation while honestly preserving the gap
to the full theoretical frontier.

Evidence required: the original source, current algorithm documentation,
committed fixtures, exported certificates, release history, and finite campaign
results. The film must let the viewer see each transformation rather than rely
on promotional assertions.

## Friction and exclusions

- The topic can feel abstract; each mathematical object must grow from the previous geometry.
- A dense graph can overwhelm; stage one local example before the global structure.
- Four dimensions can invite misleading imagery; use coordinated projections and exact inequalities.
- Benchmarks can be mistaken for proof; label finite evidence as experimental.
- Do not claim unsupported formal-boundary solving or almost-linear max flow.
- Do not make the piece resemble a generic software launch or code demo.

## Format and channels

- Main: 4:48 target, 16:9, 4K, 30 fps, English and Chinese narration/subtitles.
- Review derivative: 1920x1080 H.264 with 48 kHz stereo.
- Short derivatives: 60 seconds and 20 seconds.
- Silent loop and 16:9 thumbnail.
- Public repository and web-video delivery; no platform upload is in scope.

## Initial mood-test gate

The first implementation is a 17-second 1080p proof of visual language, not a
miniature final film. It contains archival paper, the exact `comb.json` polygon
boundary, a page-edge-to-boundary camera transition, one gold invariant reveal,
and a self-generated page/pencil sound bridge.
